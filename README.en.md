# Resource Atlas

[简体中文](./README.md) · **English**

A personal directory of sites and resources, with notes on what each site is good for.

## Resource Discovery Sites

- **[Guoke (果核剥壳)](https://www.ghxi.com/)**: Look up software and tools by name.
- **[Ziyuanhui (资源汇社区)](https://www.sucaizy.com/)**: Search by category, such as movies or games, to find other sites the community recommends.

## Unofficial Game Download Sites

- **[Gamer520](https://www.gamer520.com)**: Find PC and Switch games, including PC ports, as well as game trainers for PC.
- **[Switch618](https://www.switch618.com)**: Search by title for Chinese-language Switch games, updates, and DLC.
- **[Xiaoji (小叽资源)](https://steamzg.com)**: Browse single-player or online multiplayer games. Listings often include the version and file size.
- **[flysheep (资源避难所)](https://www.flysheep6.com)**: Browse categories such as major PC single-player releases, indie games, and VR games.
