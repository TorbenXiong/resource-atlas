# 资源知识图谱

**简体中文** · [English](./README.en.md)

收录常用的资源网站和具体资源，记下每个网站适合找什么。

## 常用资源检索站

- **[果核剥壳](https://www.ghxi.com/)**：按名称找软件或工具。
- **[资源汇社区](https://www.sucaizy.com/)**：按类别（如电影、游戏）找推荐的资源网站。

## 学习版游戏资源站

- **[Gamer520](https://www.gamer520.com)**：找 PC 和 Switch 游戏，也能找 PC 移植版和修改器。
- **[Switch618](https://www.switch618.com)**：按名称找 Switch 中文游戏的本体、更新补丁和 DLC。
- **[小叽资源](https://steamzg.com)**：按单机或联机找游戏，条目常标明版本和容量。
- **[flysheep 资源避难所](https://www.flysheep6.com)**：按分类浏览 PC 单机大作、独立游戏和 VR 游戏。
